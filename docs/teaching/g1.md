# G1 遥操录制 → Skill

本页图片来自 2026-10-15 的实际浏览器测试，使用真实 Core 工作台、MCP 代理、SQLite 技能库和 G1 录制/执行代码，底层 SDK、反馈和 VR 输入使用模拟数据。不是设计图，也不代表真机验收通过。

## 网页端怎么使用

在当前设备绑定的 G1 Driver 中添加 `g1_teaching` 执行卡，选择「录制技能」，点击原有「执行」。将执行卡接入决策核心一次，后续生成的 Skill 沿用此连接。没有新增全局按钮或专用 Web 服务。

![G1 设备检查](g1-01-check.png)

四项检查覆盖本体反馈与模式、机型与设备身份、控制状态、VR 通道。检查不申请运动权；通过通道检查后，仍需原控制器确认实时跟踪和基准。

![G1 录制](g1-02-record.png)

在原 Canvas 遥操连线启动后，由操作员松握、长按 X+A 建立基准。页面复用该会话，确认有效输入和可录制状态后开放「开始录制」。结束录制同时等待文件完成和原控制器停止交权。

![G1 试运行](g1-03-review.png)

G1_23 是双臂 10 关节、固定假手。动作曲线默认收起；不显示 PiPER 夹爪或起点位置容差。试运行明确包含先低速移动到起点的过程，执行前确认路径和接管。

![保存 G1 Skill](g1-04-save.png)

![G1 Skill 已保存](g1-05-saved.png)

保存需要回放真实完成和用户确认效果。Driver 持久化轨迹引用、SHA-256、设备/模型/几何绑定及试运行结果；Core 导入普通 Skill，下一次对话可发现，由已有 `activate_skill` 加载指令，再调用当前 G1 服务的 `g1_teaching.run`。每次执行仍需新预览与确认，沿用原回放的 `action_id` 和 ACP 完成事件。
